# hypr-conf
Моя личная Arch/Hyprland конфигурация.



######################
$ НЕОБХОДИМЫЕ ПАКЕТЫ $
######################

Для того, чтобы всё работало на Вашем ПК дожны быть установлены:
 - hyprpaper -- (для обоев)
 - waybar -- (верхнее поле с временем зашруженностью процессора и т.п)
 - hyprlock -- (блокировка устройства)
 - fastfetch -- (красивая ASCII-картинка в терминале)
 - kitty -- (терминал)
 - wlogout -- (меню выхода)
 - wofi -- (лаунчер приложений)
 - git -- (работа с GitHub)
 - firefox -- (браузер)

Так же, для правильного отображения Вам необходимы следующие шрифты:
 - JetBrains Mono
 - Noto Fonts / Noto Fonts Emoji
 - Font Awesome
 - GNU Free Fonts


####################
$ КАК ИСПОЛЬЗОВАТЬ $
####################

Запускаете 'prepare.sh' от имени админа (sudo ./prepare.sh). Данный скрипт установит на Ваш комьютер все необходимые пакеты.

Далее просто скопируйте необхдимый каталог в директорию с конфигурациями. Перезапуститесь при необходимости.
Если вы очень ленивы, то запустите скрипт 'install.sh', который всё сделает за Вас.
