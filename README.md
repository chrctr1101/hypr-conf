# hypr-conf
My personal Arch/Hyprland configuration.



#####################
$ REQUIRED PACKAGES $
#####################

For good experience you need to get on your PC:
 - hyprpaper -- (for wallpaper)
 - waybar -- (bar with time, CPU, RAM, etc.)
 - hyprlock -- (for locking your device)
 - fastfetch -- (beautiful ASCII picture in terminal)
 - kitty -- (terminal)

Also for right display you need to get next fonts:
 - JetBrains Mono
 - Noto Fonts / Noto Fonts Emoji
 - Font Awesome



##############
$ HOW TO USE $
##############

Launch 'install.sh'. This script will download on your PC all required packages

Next you need to copy desired folder to your config directory
